# Manifesto funcional

## Propósito

Ajudar a equipe comercial a gerar ofertas de fios personalizadas, corretas e auditáveis para clientes atendidos pelo WhatsApp.

## Princípios

- Dados reais prevalecem sobre texto plausível.
- Velocidade comercial não elimina aprovação e rastreabilidade.
- Cada cliente pode possuir uma lista preferencial e nomes próprios para produtos.
- Disponibilidade, chegada, frete, imposto e prazo são dimensões explícitas.
- A mensagem deve ser clara para o cliente e reconstruível pela empresa.
- O Gateway é compartilhado; a inteligência comercial permanece isolada neste serviço.

## Experiência mínima

Para um contato conhecido, o sistema identifica o cliente, seleciona produtos preferenciais, calcula condições, gera a prévia, solicita aprovação e registra exatamente o conteúdo enviado.
